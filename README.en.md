### <img align="absmiddle" src="./assets/icons/rocket.svg" width="20" height="20" alt=""> My projects

#### <img align="absmiddle" src="./assets/icons/app-window.svg" width="18" height="18" alt=""> [MacSoul](https://github.com/liu-657667/macsoul)

**A macOS developer companion with a bit of attitude.** System status, network insights, local development environments, and Codex quotas in a native main window and menu bar, with a little Soul character offering short reactions to states worth your attention.

Current public prerelease: **[v0.1.1-beta.1 · Download & installation →](https://github.com/liu-657667/macsoul/releases/tag/v0.1.1-beta.1)** · macOS 13+ · Universal DMG / ZIP

This release improves Codex protocol compatibility, launch at login, public IP query fallback, and typography and layout. I develop it mainly with AI coding assistance and am still learning SwiftUI. The Beta has no Developer ID signing or Apple notarization; see the release notes for installation instructions and validation scope.

#### <img align="absmiddle" src="./assets/icons/scan-search.svg" width="18" height="18" alt=""> [modao-prototype-inspector](https://github.com/liu-657667/modao-prototype-inspector)

**From a Modao share link to structured visual evidence.** A Python / Codex skill that scans the page tree, captures screenshots and page-switch evidence, and produces a session manifest for reviewing and analyzing prototypes.

Currently supports macOS + Chrome, with navigation through the page tree. [Usage →](https://github.com/liu-657667/modao-prototype-inspector#readme)
